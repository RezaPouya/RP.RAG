# Test Queries for Each Endpoint

These are drawn from your existing `queries.json` where possible (marked with query ID) and supplemented with additional realistic examples.

---

## 1. Lexical Search Endpoint

Lexical search relies on keyword matching (exact terms, tags, names).

| # | Query | Source | Expected Top Results |
|---|-------|--------|----------------------|
| 1 | `budget motion sensor` | Query ID 1 | Product IDs 29, 187, 262, 487, 670, 775 |
| 2 | `rechargeable desktop speakers` | Query ID 5 | Product IDs 84, 143, 165, 194, 480 |
| 3 | `wireless Bluetooth speaker` | Query ID 16 | Product IDs 161, 196, 252, 295, 569, 632, 669, 753, 780, 894 |
| 4 | `premium GaN wall charger` | Query ID 27 | Product IDs 26, 55, 519, 626, 736, 858 |
| 5 | `budget Ethernet cable` | Query ID 35 | Product IDs 409, 479, 652, 675, 696, 996 |

**Why these work:** They match directly on tag names (budget, rechargeable, wireless, bluetooth, premium), product names (GaN wall charger, Ethernet cable), and category terms.

---

## 2. Semantic Search Endpoint

Semantic search relies on meaning/intent, not exact keyword overlap.

| # | Query | Source | Expected Top Results |
|---|-------|--------|----------------------|
| 1 | `I need a tablet that charges very quickly` | Query ID 2 | Product IDs 8, 112, 156, 326, 344, 443, 493, 540, 576, 584 |
| 2 | `I need a smartphone with a high-end feel` | Query ID 3 | Product IDs 83, 94, 119, 159, 167, 215, 299, 303, 393, 396 |
| 3 | `I need a laptop with colorful lighting` | Query ID 22 | Product IDs 4, 146, 244, 324, 342, 351, 400, 406, 474, 646 |
| 4 | `I need a smartwatch that charges very quickly` | Query ID 23 | Product IDs 17, 169, 195, 236, 274, 289, 411, 454, 471, 592 |
| 5 | `I need a charger that takes up very little space` | Query ID 107 | Product IDs 13, 18, 55, 152, 178, 224, 250, 300, 370, 375 |

**Why these work:** They describe intent ("charges very quickly" → fast-charging tag, "high-end feel" → premium tag, "colorful lighting" → rgb tag, "takes up very little space" → compact tag) without using the exact tag words.

---

## 3. Hybrid Search Endpoint

Hybrid search combines lexical + semantic signals.

| # | Query | Source | Expected Top Results |
|---|-------|--------|----------------------|
| 1 | `best travel router for a premium setup` | Query ID 4 | Product IDs 545, 552 |
| 2 | `best motion sensor for cable-free use` | Query ID 6 | Product IDs 29, 262, 548, 854 |
| 3 | `best desktop speakers for a colorful setup` | Query ID 9 | Product IDs 165, 636, 785, 905 |
| 4 | `best gaming laptop for USB-C devices` | Query ID 15 | Product IDs 101, 400, 575, 643, 685, 903 |
| 5 | `best ergonomic office chair for daily use without replacing batteries` | Query ID 17 | Product IDs 574, 654, 809 |

**Why these work:** They contain both a concrete keyword anchor ("travel router", "motion sensor", "desktop speakers", "gaming laptop", "ergonomic office chair") and a semantic constraint ("premium setup", "cable-free use", "colorful setup", "USB-C devices", "without replacing batteries").

---

## 4. RAG / Ask Endpoint

RAG (Retrieval-Augmented Generation) answers natural-language questions using retrieved product data.

| # | Query | Source | What RAG Should Answer |
|---|-------|--------|------------------------|
| 1 | `What is the return policy for the Zenith Prime Mini Shower Speaker?` | Document-based | "30 days from delivery, full refund, original packaging required, free return shipping in continental US." (from product 1's return doc) |
| 2 | `How do I pair the Kestrel Neo SE keyboard?` | Document-based | "Plug in USB receiver or select Bluetooth mode with Fn+1, hold Fn+1 for 3 seconds, choose 'Kestrel Neo SE' on your computer, use Fn+Esc to reset." (from product 2's manual doc) |
| 3 | `What warranty covers the Polaris Edge Pro and for how long?` | Document-based | "12-month limited warranty against manufacturing defects. Does not cover physical damage, liquid damage, or normal wear and tear. SKU ST-POLED-0687." (from product 3's warranty doc) |
| 4 | `Which budget motion sensors do you have and what features do they offer?` | Retrieval + synthesis | Should retrieve products 29, 187, 262, 487, 670, 775 and summarize their features (Wi-Fi, compact, voice assistant, etc.) |
| 5 | `I need a tablet that charges very quickly — what do you recommend?` | Retrieval + synthesis | Should retrieve products 8, 112, 156, 326, 344, 443, 493, 540, 576, 584 and recommend based on fast-charging tag |

**Why these work:** Queries 1–3 require pulling from `documents[]` (warranty, return, manual) attached to products. Queries 4–5 require semantic retrieval + generative summarization across multiple products.

## Quick Reference: Endpoint → Query Type Mapping

| Endpoint | Query Style | Example |
|----------|-------------|---------|
| Lexical | Keywords, tags, exact names | `budget motion sensor` |
| Semantic | Intent, natural language | `I need a tablet that charges very quickly` |
| Hybrid | Keyword + intent combo | `best travel router for a premium setup` |

All 5 lexical, 5 semantic, and 5 hybrid queries above are directly from your `queries.json` with known `relevantProductIds`, so you can measure precision/recall. The RAG queries are designed to exercise the `documents` array and multi-product retrieval.

# RP.RAG

A small, readable RAG backend for a product catalog, built with .NET 10, PostgreSQL + pgvector, Elasticsearch and Ollama.

It combines keyword search (Elasticsearch) and semantic search (pgvector) with Reciprocal Rank Fusion, then lets a local LLM answer questions using only the retrieved catalog data.

## How it works

```
Seed data ──► PostgreSQL ──► Elasticsearch          (lexical index)
                  │
                  └──► chunks + embeddings ──► pgvector (HNSW, cosine)

Question ──► lexical search ─┐
                             ├─► RRF ──► top products + chunks ──► product cards (PostgreSQL)
          semantic search ───┘                                          │
                                                                        ▼
                                                      prompt (guardrails + context) ──► Ollama ──► answer
```

- **Indexer** (`RP.Rag.Indexer`) is a worker service. It seeds the database, indexes products into Elasticsearch, then chunks and embeds them with `bge-m3`.
- **Api** (`RP.Rag.Api`) serves the search endpoints and `/api/ask`.
- **Hybrid retrieval** runs both searches and fuses them with RRF (`k = 60`). Every chunk scores for its own semantic rank plus the lexical rank of its product. Products found only by keyword enter with their summary or description chunk.
- **Product cards** in the response are read from PostgreSQL, not generated by the model. The same facts (price, stock, SKU) are given to the model as context.

## Requirements

- .NET 10 SDK
- Docker (PostgreSQL with pgvector, Elasticsearch)
- [Ollama](https://ollama.com) running on the host, with the two models pulled:

```bash
ollama pull bge-m3
ollama pull gemma4:e4b
```

The generation model is configurable (`Ollama:GenerationModel`). Any chat model Ollama supports will work. Changing the embedding model requires re-embedding, and the vector column is fixed at 1024 dimensions.

## Run

```bash
docker compose up -d

# 1. start the indexer and let it finish seeding, indexing and embedding
dotnet run --project src/RP.Rag.Indexer

# 2. start the API (applies migrations in Development)
dotnet run --project src/RP.Rag.Api
```

The API listens on `http://localhost:5290`. API reference UI is at `/scalar/v1`. Ready-made requests are in `src/RP.Rag.Api/RP.Rag.Api.http`.

Ollama is commented out in `docker-compose.yml`. Uncomment it if you prefer to run it in Docker.

## Guardrails

The system prompt lives in [`src/RP.Rag.Application/Prompts/system-prompt.md`](src/RP.Rag.Application/Prompts/system-prompt.md) and is embedded into the build, so edit the file and rebuild. It restricts the assistant to:

- the catalog data given in the request, plus general knowledge for explaining terms
- no politics, no other websites or stores, no race or similar topics, no nudity or sexual content
- treating the question and context as data, not instructions

URLs are also stripped from the model output as a second check. A prompt is not a hard security boundary, so add your own moderation if you expose this publicly.

## Persian search

Text fields in the Elasticsearch index have two analyzers: `english_custom` on the field itself and `persian_custom` on its `.fa` subfield (`name.fa`, `summary.fa`, `description.fa`, `categoryName.fa`, `searchText.fa`). The lexical query searches both, so a catalog can mix English and Persian products.

`persian_custom` is built from:

- a char filter that turns the zero-width non-joiner into a space (`می‌خواهم` becomes two tokens)
- `standard` tokenizer, `lowercase`, `decimal_digit` (Persian digits to ASCII, so `۱۲۸` matches `128`)
- `arabic_normalization` and `persian_normalization` (Arabic ya/kaf to Persian, so both spellings match)
- Persian stop words
- a conservative plural-suffix filter that strips `ها` and `های` only when at least three letters remain

The multi-field fallback requires every term for one or two word queries and 75% of the terms for longer ones.

Changing the mapping needs a reindex. The indexer skips products whose `ContentChanged` flag is false, so reset it too:

```bash
curl -X DELETE http://localhost:9200/products
```

```sql
UPDATE "ProductSyncs" SET "ContentChanged" = true, "ContentSyncRetries" = 0;
```

Then restart the API (it recreates the index) and the indexer. To compare analyzers, call `POST /products/_analyze` with `{"field": "name.fa", "text": "..."}`.

## Change tracking

`ProductSyncInterceptor` marks a product for re-indexing and re-embedding when its name, summary, description, SKU, category, active flag, tags or documents change. It only collects ids while saving and runs one `UPDATE` on `ProductSyncs` after the save succeeded. It is registered as a singleton in `AddInfrastructure`.

using Microsoft.AspNetCore.Mvc;
using RP.RAG.Application.Ask;

namespace RP.RAG.Api.Controllers;

[ApiController]
[Route("api/ask")]
public sealed class AskController(
    IAskService ask,
    ILogger<AskController> logger) : ControllerBase
{
    [HttpPost]
    public async Task<IActionResult> Ask([FromBody] AskRequest request, CancellationToken ct)
    {
        if (string.IsNullOrWhiteSpace(request.Question))
            return BadRequest(new { error = "Field 'question' is required." });

        try
        {
            return Ok(await ask.AskAsync(request.Question, request.TopK, ct));
        }
        catch (HttpRequestException ex)
        {
            logger.LogError(ex, "The language model request failed.");
            return StatusCode(StatusCodes.Status502BadGateway,
                new { error = "The language model is not available." });
        }
    }
}

public sealed class AskRequest
{
    public string Question { get; init; } = "";
    public int? TopK { get; init; }
}

using RP.RAG.Application.Catalog;
using RP.RAG.Application.Search.Models;
using System.Globalization;
using System.Reflection;
using System.Text;

namespace RP.RAG.Application.Ask;

public sealed class PromptBuilder
{
    private const string ResourceName = "system-prompt.md";

    public string SystemPrompt { get; }

    public PromptBuilder()
    {
        using var stream = Assembly.GetExecutingAssembly().GetManifestResourceStream(ResourceName)
            ?? throw new InvalidOperationException($"Embedded resource '{ResourceName}' was not found.");

        using var reader = new StreamReader(stream);
        SystemPrompt = reader.ReadToEnd().Trim();
    }

    public string BuildUserPrompt(
        string question,
        IReadOnlyList<ProductCard> products,
        IReadOnlyList<ChunkHit> chunks)
    {
        var sb = new StringBuilder();

        sb.AppendLine("<context>");

        for (var i = 0; i < products.Count; i++)
        {
            var p = products[i];

            sb.AppendLine($"[{i + 1}] {p.Name}");
            sb.AppendLine($"SKU: {p.Sku}");
            sb.AppendLine($"Category: {p.CategoryName}");

            if (p.Tags.Count > 0)
                sb.AppendLine($"Tags: {string.Join(", ", p.Tags)}");

            sb.AppendLine($"Price: {p.Price.ToString("0.##", CultureInfo.InvariantCulture)}");
            sb.AppendLine(p.InStock ? $"Stock: in stock ({p.StockCount} units)" : "Stock: out of stock");

            foreach (var chunk in chunks.Where(c => c.ProductId == p.ProductId))
            {
                var label = string.IsNullOrWhiteSpace(chunk.Header) ? chunk.ChunkType : chunk.Header;
                sb.AppendLine($"Excerpt ({label}): {chunk.Text.Trim()}");
            }

            sb.AppendLine();
        }

        sb.AppendLine("</context>");
        sb.AppendLine();
        sb.AppendLine("<question>");
        sb.AppendLine(question);
        sb.AppendLine("</question>");

        return sb.ToString();
    }
}

using RP.Rag.Domain.Entities.Products;
using System.Security.Cryptography;
using System.Text;

namespace RP.RAG.Application.Embeddings;

public sealed class ProductChunkBuilder
{
    private const int MaxChunkChars = 800;
    private const int MinChunkChars = 50;
    private const int MaxNamePrefixChars = 80;

    public List<ProductChunk> Build(Product product)
    {
        var chunks = new List<ProductChunk>();
        var namePrefix = BuildNamePrefix(product);

        AddSummary(chunks, product);

        AddSection(chunks, product, namePrefix,
            chunkType: "description",
            header: "Description",
            content: product.Description,
            documentId: null);

        foreach (var doc in product.Documents.Where(d => d.IsActive))
        {
            AddSection(chunks, product, namePrefix,
                chunkType: "document",
                header: doc.Title,
                content: doc.Content,
                documentId: doc.Id);
        }

        return chunks;
    }

    private static void AddSummary(List<ProductChunk> chunks, Product p)
    {
        var parts = new List<string>();

        if (!string.IsNullOrWhiteSpace(p.Name)) parts.Add(p.Name);
        if (!string.IsNullOrWhiteSpace(p.Summary)) parts.Add(p.Summary);

        var cats = p.Category?.Name;
        if (!string.IsNullOrWhiteSpace(cats)) parts.Add(cats);

        if (parts.Count == 0) return;

        var text = string.Join(" | ", parts);

        chunks.Add(new ProductChunk
        {
            ProductId = p.Id,
            ChunkType = "summary",
            Ordinal = 0,
            Header = "Summary",
            ChunkText = text,
            EmbeddingText = text,
            ChunkTextHash = Hash(text),
            IsActive = p.IsActive,
            EmbeddingStatus = "Pending"
        });
    }

    private static void AddSection(
        List<ProductChunk> chunks,
        Product p,
        string namePrefix,
        string chunkType,
        string header,
        string? content,
        int? documentId)
    {
        if (string.IsNullOrWhiteSpace(content)) return;

        var text = content.Trim();

        if (text.Length <= MaxChunkChars)
        {
            AddChunk(chunks, p, namePrefix, chunkType, header,
                documentId, 0, text);
            return;
        }

        var paragraphs = text.Split(
            new[] { "\n\n", "\r\n\r\n" },
            StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);

        var ordinal = 0;
        var buffer = new StringBuilder();

        void Flush()
        {
            if (buffer.Length < MinChunkChars) { buffer.Clear(); return; }

            AddChunk(chunks, p, namePrefix, chunkType, header,
                documentId, ordinal++, buffer.ToString().Trim());

            buffer.Clear();
        }

        foreach (var para in paragraphs)
        {
            if (buffer.Length > 0 && buffer.Length + para.Length + 2 > MaxChunkChars)
                Flush();

            if (buffer.Length > 0) buffer.Append("\n\n");
            buffer.Append(para);
        }

        Flush();
    }

    private static void AddChunk(
        List<ProductChunk> chunks,
        Product p,
        string namePrefix,
        string chunkType,
        string header,
        int? documentId,
        int ordinal,
        string text)
    {
        var embeddingText = string.IsNullOrWhiteSpace(namePrefix)
            ? $"{header}\n{text}"
            : $"{header} — {namePrefix}\n{text}";

        chunks.Add(new ProductChunk
        {
            ProductId = p.Id,
            DocumentId = documentId,
            ChunkType = chunkType,
            Ordinal = ordinal,
            Header = header,
            ChunkText = text,
            EmbeddingText = embeddingText,
            ChunkTextHash = Hash(text),
            IsActive = p.IsActive,
            EmbeddingStatus = "Pending"
        });
    }

    private static string BuildNamePrefix(Product p)
    {
        var parts = new[] { p.Name, p.Category?.Name }
            .Where(s => !string.IsNullOrWhiteSpace(s))
            .ToArray();

        var s = string.Join(" ", parts);

        return TruncateSafe(s, MaxNamePrefixChars);
    }

    // Avoids cutting a UTF-16 surrogate pair in half.
    private static string TruncateSafe(string s, int maxChars)
    {
        if (string.IsNullOrEmpty(s) || s.Length <= maxChars) return s;

        var end = maxChars;

        if (char.IsHighSurrogate(s[end - 1]))
            end--;

        return s[..end];
    }

    private static string Hash(string text)
    {
        var bytes = SHA256.HashData(Encoding.UTF8.GetBytes(text ?? string.Empty));
        return Convert.ToHexString(bytes);
    }
}

namespace RP.RAG.Application.Search;

public sealed class CategoryTokenIndex
{
    private readonly IReadOnlyDictionary<string, IReadOnlyDictionary<string, double>> _weights;

    private CategoryTokenIndex(IReadOnlyDictionary<string, IReadOnlyDictionary<string, double>> weights)
    {
        _weights = weights;
    }

    public static CategoryTokenIndex Empty { get; } = new(new Dictionary<string, IReadOnlyDictionary<string, double>>());

    public int CategoryCount => _weights.Count;

    public string? DetectCategory(string query)
    {
        if (string.IsNullOrWhiteSpace(query) || _weights.Count == 0)
        {
            return null;
        }

        var queryTokens = Tokenize(query);

        if (queryTokens.Count == 0)
        {
            return null;
        }

        var scores = new Dictionary<string, double>(StringComparer.OrdinalIgnoreCase);

        foreach (var (category, categoryWeights) in _weights)
        {
            var categoryScore = 0.0;

            foreach (var token in queryTokens)
            {
                if (categoryWeights.TryGetValue(token, out var weight))
                {
                    categoryScore += weight;
                }
            }

            if (categoryScore > 0)
            {
                scores[category] = categoryScore;
            }
        }

        if (scores.Count == 0)
        {
            return null;
        }

        var top = scores.OrderByDescending(kv => kv.Value).First();

        var second = scores
            .Where(kv => !string.Equals(kv.Key, top.Key, StringComparison.OrdinalIgnoreCase))
            .Select(kv => kv.Value)
            .DefaultIfEmpty(0.0)
            .Max();

        if (top.Value < 0.3 || top.Value < second * 1.5)
        {
            return null;
        }

        return top.Key;
    }

    public static CategoryTokenIndex Create(IReadOnlyDictionary<string, IReadOnlyDictionary<string, double>> weights)
        => new(weights);

    public static HashSet<string> Tokenize(string text)
    {
        if (string.IsNullOrWhiteSpace(text))
        {
            return new HashSet<string>(StringComparer.OrdinalIgnoreCase);
        }

        return text
            .ToLowerInvariant()
            .Split(
                [' ', '-', '_', '/', '\\', '.', ',', ';', ':', '!', '?', '(', ')', '[', ']', '{', '}'],
                StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries)
            .Where(t => t.Length > 2)
            .ToHashSet(StringComparer.OrdinalIgnoreCase);
    }
}

using RP.RAG.Application.Search.Models;

namespace RP.RAG.Application.Search;

public static class HybridRanker
{
    public const int DefaultK = 60;

    public static double Score(int rank, int k = DefaultK) => 1.0 / (k + rank);

    public static List<ChunkHit> Fuse(
        IReadOnlyList<ChunkHit> semanticChunks,
        IReadOnlyList<int> lexicalIds,
        IReadOnlyList<ChunkHit> lexicalOnlyChunks,
        int k = DefaultK)
    {
        var lexicalRank = new Dictionary<int, int>();

        for (var i = 0; i < lexicalIds.Count; i++)
        {
            lexicalRank.TryAdd(lexicalIds[i], i + 1);
        }

        var fused = new Dictionary<long, ChunkHit>();

        for (var i = 0; i < semanticChunks.Count; i++)
        {
            var chunk = semanticChunks[i];

            var score = Score(i + 1, k);

            if (lexicalRank.TryGetValue(chunk.ProductId, out var rank))
            {
                score += Score(rank, k);
            }

            fused.TryAdd(chunk.ChunkId, chunk with { Score = score });
        }

        foreach (var chunk in lexicalOnlyChunks)
        {
            if (fused.ContainsKey(chunk.ChunkId))
            {
                continue;
            }

            if (!lexicalRank.TryGetValue(chunk.ProductId, out var rank))
            {
                continue;
            }

            fused[chunk.ChunkId] = chunk with { Score = Score(rank, k) };
        }

        return fused.Values
            .OrderByDescending(c => c.Score)
            .ThenBy(c => c.ChunkId)
            .ToList();
    }
}

using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Options;
using RP.Rag.Domain.Entities.Products;
using RP.Rag.Infrastructure.Data;
using RP.Rag.Infrastructure.SeedData;

namespace RP.Rag.Indexer.Workers;

public sealed class DataSeederWorker(IServiceScopeFactory scopeFactory, IOptions<DataSeederWorkerOptions> options,
    ILogger<DataSeederWorker> logger) : BackgroundService
{
    private static bool _shouldContinue = true;

    protected override async Task ExecuteAsync(CancellationToken stoppingToken)
    {
        var opts = options.Value;

        logger.LogInformation("DataSeederWorker starting. BatchSize={BatchSize}", opts.BatchSize);

        try
        {
            if (!_shouldContinue)
                return;

            await InitializeAsync(opts, stoppingToken);
        }
        catch (OperationCanceledException) when (stoppingToken.IsCancellationRequested)
        {
            return;
        }
        catch (Exception ex)
        {
            logger.LogCritical(ex, "ProductSync initialization failed.");
            throw;
        }

        logger.LogInformation("DataSeederWorker completed.");
    }

    private async Task InitializeAsync(DataSeederWorkerOptions opts, CancellationToken ct)
    {
        await SeedAsync(ct);

        var totalCreated = 0;

        while (!ct.IsCancellationRequested)
        {
            using var scope = scopeFactory.CreateScope();

            var db = scope.ServiceProvider.GetRequiredService<RpRagDbContext>();

            var syncedProductIds = await db.ProductSyncs
                .AsNoTracking()
                .Select(p => p.ProductId)
                .ToListAsync(ct);

            var productIds = await db.Products
                .AsNoTracking()
                .Where(p => !syncedProductIds.Contains(p.Id))
                .OrderBy(p => p.Id)
                .Select(p => p.Id)
                .Take(opts.BatchSize)
                .ToListAsync(ct);

            if (productIds.Count == 0)
            {
                _shouldContinue = false;
                break;
            }

            var now = DateTime.UtcNow;

            var syncRows = productIds.Select(productId => new ProductSync
            {
                ProductId = productId,
                ContentChanged = true,
                EmbeddingChanged = false,
                CreatedAt = now,
                UpdatedAt = now
            }).ToList();

            db.ProductSyncs.AddRange(syncRows);
            await db.SaveChangesAsync(ct);

            totalCreated += syncRows.Count;

            logger.LogInformation(
                "Created {Count} ProductSync rows. TotalCreated={TotalCreated}",
                syncRows.Count,
                totalCreated);
        }

        logger.LogInformation("ProductSync initialization finished. TotalCreated={TotalCreated}", totalCreated);
    }

    private async Task SeedAsync(CancellationToken ct)
    {
        using var scope = scopeFactory.CreateScope();

        var seedLoader = scope.ServiceProvider.GetRequiredService<SeedLoader>();
        var configuration = scope.ServiceProvider.GetRequiredService<IConfiguration>();
        var env = scope.ServiceProvider.GetRequiredService<IHostEnvironment>();

        var configured = configuration["Seed:DataRoot"];

        var dataRoot = !string.IsNullOrWhiteSpace(configured)
            ? Path.GetFullPath(configured)
            : Path.GetFullPath(Path.Combine(env.ContentRootPath, "..", "..", "data"));

        try
        {
            await seedLoader.LoadAsync(dataRoot, locale: "", clearExisting: false, ct);
        }
        catch (Exception ex) when (ex is not OperationCanceledException)
        {
            logger.LogError(ex, "Seeding from {DataRoot} failed.", dataRoot);
        }
    }
}

        logger.LogInformation(
            "EmbeddingWorker starting. " +
            "Model={Model}, Dims={Dims}, PollInterval={Poll}s, " +
            "BatchSize={Batch}, MaxChunksPerBatch={MaxChunks}, " +
            "MaxRetries={MaxRetries}",
            embedder.ModelName,
            embedder.Dimensions,
            opts.PollIntervalSeconds,
            opts.BatchSize,
            opts.MaxChunksPerBatch,
            MaxRetries);

        using var timer = new PeriodicTimer(TimeSpan.FromSeconds(opts.PollIntervalSeconds));

        while (!stoppingToken.IsCancellationRequested)
        {
            try
            {
                await RunAsync(stoppingToken);
            }
            catch (OperationCanceledException) when (stoppingToken.IsCancellationRequested)
            {
                break;
            }
            catch (Exception ex)
            {
                logger.LogError(ex, "Embedding iteration failed. Will retry on next tick.");
            }

            try
            {
                if (!await timer.WaitForNextTickAsync(stoppingToken))
                    break;
            }
            catch (OperationCanceledException)
            {
                break;
            }
        }

        logger.LogInformation("EmbeddingWorker stopped.");
    }

    private async Task RunAsync(CancellationToken ct)
    {
        using var scope = scopeFactory.CreateScope();

        var db = scope.ServiceProvider.GetRequiredService<RpRagDbContext>();

        var opts = options.Value;

        var pending = await db.ProductSyncs
            .Where(s => s.EmbeddingChanged && s.EmbeddingSyncRetries < MaxRetries)
            .OrderBy(s => s.UpdatedAt)
            .Take(opts.BatchSize)
            .ToListAsync(ct);

        if (pending.Count == 0)
            return;

        logger.LogInformation("Processing {Count} pending embeddings.", pending.Count);

        var productIds = pending.Select(s => s.ProductId).ToList();

        var syncMap = pending.ToDictionary(s => s.ProductId);

        var products = await db.Products.AsNoTracking()
            .Include(p => p.Category)
            .Include(p => p.ProductTags)
                .ThenInclude(pt => pt.Tag)
            .Include(p => p.Documents)
            .Where(p => productIds.Contains(p.Id))
            .ToDictionaryAsync(p => p.Id, ct);

        var chunkBuilder = new ProductChunkBuilder();

        var chunksByProduct = new Dictionary<int, List<ProductChunk>>();

        foreach (var productId in productIds)
        {
            if (!products.TryGetValue(productId, out var product))
            {
                var sync = syncMap[productId];
                var now = DateTime.UtcNow;

                sync.EmbeddingChanged = false;
                sync.EmbeddingSyncedAt = now;
                sync.EmbeddingSyncRetries = 0;
                sync.EmbeddingSyncError = null;
                sync.UpdatedAt = now;

                continue;
            }

            var chunks = chunkBuilder.Build(product);

            if (chunks.Count > 0)
            {
                chunksByProduct[productId] = chunks;
            }
        }

        var allChunks = chunksByProduct.SelectMany(x => x.Value).ToList();


        if (allChunks.Count > 0)
        {
            try
            {
                var maxChunksPerBatch = Math.Max(1, opts.MaxChunksPerBatch);

                foreach (var chunkBatch in Chunk(allChunks, maxChunksPerBatch))
                {
                    ct.ThrowIfCancellationRequested();

                    var embeddingTexts = chunkBatch
                        .Select(c => c.EmbeddingText)
                        .ToList();

                    var vectors = await GenerateBatchWithRetryAsync(embeddingTexts, ct);

                    if (vectors.Length != chunkBatch.Count)
                    {
                        throw new InvalidOperationException(
                            $"Embedding provider returned " +
                            $"{vectors.Length} vectors for " +
                            $"{chunkBatch.Count} input texts.");
                    }

                    AttachEmbeddings(chunkBatch, vectors);
                }
            }
            catch (OperationCanceledException)
            {
                throw;
            }
            catch (Exception ex)
            {
                logger.LogError(ex, "Embedding generation failed for {Count} chunks.", allChunks.Count);

                await RecordFailureAsync(productIds, ex, ct);

                return;
            }
        }


        await using var tx = await db.Database.BeginTransactionAsync(ct);

        try
        {
            var oldChunks = await db.ProductChunks
                .Where(c => productIds.Contains(c.ProductId))
                .ToListAsync(ct);

            db.ProductChunks.RemoveRange(oldChunks);

            foreach (var chunk in allChunks)
            {
                chunk.Id = 0;

                db.ProductChunks.Add(chunk);
            }

            var now = DateTime.UtcNow;

            foreach (var sync in pending)
            {
                sync.EmbeddingChanged = false;
                sync.EmbeddingSyncedAt = now;
                sync.EmbeddingSyncRetries = 0;
                sync.EmbeddingSyncError = null;
                sync.UpdatedAt = now;
            }

            await db.SaveChangesAsync(ct);

            await tx.CommitAsync(ct);

            logger.LogInformation("Embedding complete. Products={Products}, Chunks={Chunks}.", pending.Count, allChunks.Count);
        }
        catch (OperationCanceledException)
        {
            await tx.RollbackAsync(CancellationToken.None);
            throw;
        }
        catch (Exception ex)
        {
            await tx.RollbackAsync(CancellationToken.None);

            logger.LogError(ex, "Failed to persist embeddings.");

            await RecordFailureAsync(productIds, ex, ct);
        }
    }

    private void AttachEmbeddings(IReadOnlyList<ProductChunk> chunks, IReadOnlyList<Vector> vectors)
    {
        for (var i = 0; i < chunks.Count; i++)
        {
            chunks[i].Embedding = vectors[i];
            chunks[i].EmbeddingModel = embedder.ModelName;
            chunks[i].EmbeddingVersion = EmbeddingVersion;
            chunks[i].EmbeddingStatus = "Completed";
        }
    }

    private async Task RecordFailureAsync(IReadOnlyCollection<int> productIds, Exception exception, CancellationToken ct)
    {
        using var scope = scopeFactory.CreateScope();

        var db = scope.ServiceProvider.GetRequiredService<RpRagDbContext>();

        var syncs = await db.ProductSyncs.Where(s => productIds.Contains(s.ProductId)).ToListAsync(ct);

        var now = DateTime.UtcNow;

        foreach (var sync in syncs)
        {
            sync.EmbeddingSyncRetries++;

            sync.EmbeddingSyncError = Truncate(exception.Message, 500);

            sync.UpdatedAt = now;
        }

        await db.SaveChangesAsync(ct);
    }

    private async Task<Vector[]> GenerateBatchWithRetryAsync(IReadOnlyList<string> texts, CancellationToken ct)
    {
        for (var attempt = 1; attempt <= MaxRetries; attempt++)
        {
            try
            {
                return await embedder.GenerateBatchAsync(texts, ct);
            }
            catch (OperationCanceledException)
            {
                throw;
            }
            catch (Exception ex)
            {
                if (attempt == MaxRetries)
                    throw;

                var delay = TimeSpan.FromSeconds(Math.Pow(2, attempt));

                logger.LogWarning(
                    ex,
                    "Batch attempt {Attempt}/{Max} failed: " +
                    "{Message}. Retrying in {Delay:F0}s...",
                    attempt,
                    MaxRetries,
                    ex.Message,
                    delay.TotalSeconds);

                await Task.Delay(delay, ct);
            }
        }

        throw new InvalidOperationException("Embedding generation failed unexpectedly.");
    }

    private static IEnumerable<List<T>> Chunk<T>(IReadOnlyList<T> source, int size)
    {
        for (var i = 0; i < source.Count; i += size)
        {
            var count = Math.Min(size, source.Count - i);

            var batch = new List<T>(count);

            for (var j = 0; j < count; j++)
            {
                batch.Add(source[i + j]);
            }

            yield return batch;
        }
    }

    private static string Truncate(string? value, int max)
    {
        if (string.IsNullOrEmpty(value))
            return string.Empty;

        return value.Length <= max ? value : value[..max] + "…";
    }
}

using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using RP.RAG.Application.Ask;
using RP.RAG.Application.Catalog;
using RP.RAG.Application.Search;
using System.Diagnostics;
using System.Text.RegularExpressions;

namespace RP.RAG.Infrastructure.Ask;

public sealed class AskService(
    IHybridSearch hybrid,
    IProductCatalogService catalog,
    IAnswerGenerator generator,
    PromptBuilder prompts,
    IOptions<AskOptions> options,
    ILogger<AskService> logger) : IAskService
{
    private static readonly Regex UrlPattern = new(@"(https?://|www\.)\S+", RegexOptions.IgnoreCase | RegexOptions.Compiled);

    public async Task<AskResponse> AskAsync(string question, int? topProducts = null, CancellationToken ct = default)
    {
        var opts = options.Value;
        var sw = Stopwatch.StartNew();

        question = question.Trim();

        if (question.Length > opts.MaxQuestionLength)
            question = question[..opts.MaxQuestionLength];

        var retrieval = await hybrid.RetrieveAsync(
            question,
            topProducts ?? opts.TopProducts,
            opts.ChunksPerProduct,
            onlyActive: true,
            ct);

        var cards = await catalog.GetCardsAsync(retrieval.ProductIds, onlyActive: true, ct);

        var products = retrieval.ProductIds
            .Where(cards.ContainsKey)
            .Select(id => cards[id])
            .ToList();

        if (products.Count == 0)
        {
            return new AskResponse
            {
                Question = question,
                Answer = opts.NoResultsAnswer,
                TookMs = sw.ElapsedMilliseconds
            };
        }

        var productIds = products.Select(p => p.ProductId).ToHashSet();

        var chunks = retrieval.Chunks.Where(c => productIds.Contains(c.ProductId)).ToList();

        var userPrompt = prompts.BuildUserPrompt(question, products, chunks);

        var raw = await generator.GenerateAsync(prompts.SystemPrompt, userPrompt, ct);

        var answer = UrlPattern.Replace(raw, "").Trim();

        var refByProduct = products
            .Select((p, i) => (p.ProductId, Ref: i + 1))
            .ToDictionary(x => x.ProductId, x => x.Ref);

        sw.Stop();

        logger.LogInformation(
            "Ask '{Question}': {Products} products, {Chunks} chunks, {Ms}ms",
            question, products.Count, chunks.Count, sw.ElapsedMilliseconds);

        return new AskResponse
        {
            Question = question,
            Answer = answer,
            Model = generator.ModelName,
            TookMs = sw.ElapsedMilliseconds,
            Products = products,
            Sources = chunks
                .Select(c => new AskSource
                {
                    ProductRef = refByProduct[c.ProductId],
                    ProductId = c.ProductId,
                    ChunkType = c.ChunkType,
                    Header = c.Header
                })
                .ToList()
        };
    }
}

public sealed class OllamaAnswerGenerator : IAnswerGenerator
{
    private readonly HttpClient _http;
    private readonly OllamaOptions _options;

    public string ModelName => _options.GenerationModel;

    public OllamaAnswerGenerator(IHttpClientFactory httpFactory, IOptions<OllamaOptions> options)
    {
        _http = httpFactory.CreateClient("Ollama");
        _options = options.Value;
    }

    public async Task<string> GenerateAsync(
        string systemPrompt,
        string userPrompt,
        CancellationToken ct = default)
    {
        var request = new ChatRequest
        {
            Model = _options.GenerationModel,
            Stream = false,
            Options = new ChatOptions { Temperature = _options.Temperature },
            Messages =
            [
                new ChatMessage { Role = "system", Content = systemPrompt },
                new ChatMessage { Role = "user", Content = userPrompt }
            ]
        };

        using var response = await _http.PostAsJsonAsync("/api/chat", request, ct);

        if (!response.IsSuccessStatusCode)
        {
            var body = await response.Content.ReadAsStringAsync(ct);
            throw new HttpRequestException(
                $"Ollama returned {(int)response.StatusCode}: {body}",
                inner: null,
                statusCode: response.StatusCode);
        }

        var result = await response.Content.ReadFromJsonAsync<ChatResponse>(ct);
        var content = result?.Message?.Content;

        if (string.IsNullOrWhiteSpace(content))
            throw new InvalidOperationException("Ollama returned an empty answer.");

        return content.Trim();
    }

    {
        [JsonPropertyName("model")] public string Model { get; set; } = "";
        [JsonPropertyName("stream")] public bool Stream { get; set; }
        [JsonPropertyName("messages")] public List<ChatMessage> Messages { get; set; } = new();
        [JsonPropertyName("options")] public ChatOptions? Options { get; set; }
    }

    private sealed class ChatMessage
    {
        [JsonPropertyName("role")] public string Role { get; set; } = "";
        [JsonPropertyName("content")] public string Content { get; set; } = "";
    }

    private sealed class ChatOptions
    {
        [JsonPropertyName("temperature")] public double Temperature { get; set; }
    }

    private sealed class ChatResponse
    {
        [JsonPropertyName("message")] public ChatMessage? Message { get; set; }
    }

using Microsoft.EntityFrameworkCore.Diagnostics;
using RP.Rag.Domain.Entities.Products;
using System.Runtime.CompilerServices;

namespace RP.RAG.Infrastructure.Data.Interceptors;

// Flags a product for re-indexing when its searchable content changes.
// It only collects ids while saving and updates ProductSync after the save succeeded,
// with one set-based UPDATE. It never queries or saves from inside SaveChanges.
// Register it once as a singleton: a new instance per DbContext makes EF build
// a new internal service provider every time.
public sealed class ProductSyncInterceptor : SaveChangesInterceptor
{
    private static readonly HashSet<string> ContentProperties = new()
    {
        nameof(Product.Name),
        nameof(Product.Summary),
        nameof(Product.Description),
        nameof(Product.SKU),
        nameof(Product.ProductCategoryId),
        nameof(Product.IsActive)
    };

    private readonly ConditionalWeakTable<DbContext, Pending> _pending = new();

    public override InterceptionResult<int> SavingChanges(
        DbContextEventData eventData,
        InterceptionResult<int> result)
    {
        Collect(eventData.Context);
        return base.SavingChanges(eventData, result);
    }

    public override ValueTask<InterceptionResult<int>> SavingChangesAsync(
        DbContextEventData eventData,
        InterceptionResult<int> result,
        CancellationToken cancellationToken = default)
    {
        Collect(eventData.Context);
        return base.SavingChangesAsync(eventData, result, cancellationToken);
    }

    public override int SavedChanges(SaveChangesCompletedEventData eventData, int result)
    {
        var ids = Resolve(eventData.Context);

        if (ids.Count > 0)
        {
            Flag(eventData.Context!, ids)
                .ExecuteUpdate(Apply(DateTime.UtcNow));
        }

        return base.SavedChanges(eventData, result);
    }

    public override async ValueTask<int> SavedChangesAsync(
        SaveChangesCompletedEventData eventData,
        int result,
        CancellationToken cancellationToken = default)
    {
        var ids = Resolve(eventData.Context);

        if (ids.Count > 0)
        {
            await Flag(eventData.Context!, ids)
                .ExecuteUpdateAsync(Apply(DateTime.UtcNow), cancellationToken);
        }

        return await base.SavedChangesAsync(eventData, result, cancellationToken);
    }

    public override void SaveChangesFailed(DbContextErrorEventData eventData)
    {
        Discard(eventData.Context);
        base.SaveChangesFailed(eventData);
    }

    public override Task SaveChangesFailedAsync(
        DbContextErrorEventData eventData,
        CancellationToken cancellationToken = default)
    {
        Discard(eventData.Context);
        return base.SaveChangesFailedAsync(eventData, cancellationToken);
    }

    private void Collect(DbContext? context)
    {
        if (context is null)
            return;

        var pending = _pending.GetOrCreateValue(context);
        pending.Clear();

        foreach (var entry in context.ChangeTracker.Entries())
        {
            switch (entry.Entity)
            {
                case Product product when entry.State == EntityState.Modified && HasContentChange(entry):
                    pending.ProductIds.Add(product.Id);
                    break;

                case ProductTag tag when entry.State == EntityState.Deleted:
                    pending.ProductIds.Add(tag.ProductId);
                    break;

                case ProductTag tag when entry.State == EntityState.Added:
                    pending.Added.Add(tag);
                    break;

                case ProductDocument doc when entry.State is EntityState.Modified or EntityState.Deleted:
                    pending.ProductIds.Add(doc.ProductId);
                    break;

                case ProductDocument doc when entry.State == EntityState.Added:
                    pending.Added.Add(doc);
                    break;
            }
        }
    }

    // Tags and documents added together with a new product only get their ProductId
    // after the save. Products without a ProductSync row yet are simply not matched.
    private List<int> Resolve(DbContext? context)
    {
        if (context is null || !_pending.TryGetValue(context, out var pending))
            return [];

        foreach (var added in pending.Added)
        {
            switch (added)
            {
                case ProductTag tag:
                    pending.ProductIds.Add(tag.ProductId);
                    break;
                case ProductDocument doc:
                    pending.ProductIds.Add(doc.ProductId);
                    break;
            }
        }

        var ids = pending.ProductIds.Where(id => id > 0).ToList();
        pending.Clear();

        return ids;
    }

    private void Discard(DbContext? context)
    {
        if (context is not null && _pending.TryGetValue(context, out var pending))
            pending.Clear();
    }

    private static IQueryable<ProductSync> Flag(DbContext context, List<int> productIds)
        => context.Set<ProductSync>().Where(s => productIds.Contains(s.ProductId));

    private static Action<Microsoft.EntityFrameworkCore.Query.UpdateSettersBuilder<ProductSync>> Apply(DateTime now)
        => set => set
            .SetProperty(s => s.ContentChanged, true)
            .SetProperty(s => s.EmbeddingChanged, false)
            .SetProperty(s => s.ContentSyncRetries, 0)
            .SetProperty(s => s.EmbeddingSyncRetries, 0)
            .SetProperty(s => s.UpdatedAt, now);

    private static bool HasContentChange(EntityEntry entry)
    {
        foreach (var property in entry.Properties)
        {
            if (property.IsModified && ContentProperties.Contains(property.Metadata.Name))
                return true;
        }

        return false;
    }

    private sealed class Pending
    {
        public HashSet<int> ProductIds { get; } = new();
        public List<object> Added { get; } = new();

        public void Clear()
        {
            ProductIds.Clear();
            Added.Clear();
        }
    }
}

using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using RP.Rag.Infrastructure.Data;
using RP.RAG.Application.Search;

namespace RP.RAG.Infrastructure.Elastic;

public sealed class CategoryTokenIndexBuilder(
    IDbContextFactory<RpRagDbContext> dbFactory,
    ILogger<CategoryTokenIndexBuilder> logger)
{
    private const int MinProductsPerCategory = 3;
    private const int MaxOtherCategoriesForToken = 2;
    private const double MinNormalizedWeight = 0.15;

    private static readonly string[] ExcludedCategories =
    [
        "Unknown",
        "Misc"
    ];

    public async Task<CategoryTokenIndex> BuildAsync(CancellationToken ct = default)
    {
        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var rows = await db.Products
            .AsNoTracking()
            .Where(p => p.IsActive)
            .Select(p => new
            {
                CategoryName = p.Category != null ? p.Category.Name : null,
                p.Name,
                p.Summary,
                p.Description,
                Tags = p.ProductTags.Select(pt => pt.Tag.Name).ToList()
            })
            .ToListAsync(ct);

        if (rows.Count == 0)
        {
            logger.LogWarning("Category token index: no products found.");
            return CategoryTokenIndex.Empty;
        }

        var perCategory = new Dictionary<string, Dictionary<string, int>>(StringComparer.OrdinalIgnoreCase);
        var categoryCounts = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase);

        foreach (var row in rows)
        {
            var category = row.CategoryName;

            if (string.IsNullOrWhiteSpace(category))
            {
                continue;
            }

            if (ExcludedCategories.Contains(category, StringComparer.OrdinalIgnoreCase))
            {
                continue;
            }

            categoryCounts[category] = categoryCounts.GetValueOrDefault(category) + 1;

            var tokens = new HashSet<string>(StringComparer.OrdinalIgnoreCase);

            AddTokens(tokens, row.Name);
            AddTokens(tokens, row.Summary);
            AddTokens(tokens, row.Description);

            foreach (var tag in row.Tags)
            {
                AddTokens(tokens, tag);
            }

            if (!perCategory.TryGetValue(category, out var categoryWeights))
            {
                categoryWeights = new Dictionary<string, int>(StringComparer.OrdinalIgnoreCase);
                perCategory[category] = categoryWeights;
            }

            foreach (var token in tokens)
            {
                categoryWeights[token] = categoryWeights.GetValueOrDefault(token) + 1;
            }
        }

        var categories = perCategory.Keys.ToList();

        // Map token -> list of categories that contain it
        var tokenCategoryPresence = new Dictionary<string, List<string>>(StringComparer.OrdinalIgnoreCase);

        foreach (var (category, weights) in perCategory)
        {
            foreach (var token in weights.Keys)
            {
                if (!tokenCategoryPresence.TryGetValue(token, out var list))
                {
                    list = new List<string>();
                    tokenCategoryPresence[token] = list;
                }

                list.Add(category);
            }
        }

        var filtered = new Dictionary<string, IReadOnlyDictionary<string, double>>(StringComparer.OrdinalIgnoreCase);

        foreach (var (category, weights) in perCategory)
        {
            var categoryProductCount = categoryCounts[category];

            if (categoryProductCount < MinProductsPerCategory)
            {
                logger.LogDebug(
                    "Category '{Category}' skipped: only {Count} products (min={Min}).",
                    category,
                    categoryProductCount,
                    MinProductsPerCategory);

                continue;
            }

            var normalized = new Dictionary<string, double>(StringComparer.OrdinalIgnoreCase);

            foreach (var (token, frequency) in weights)
            {
                var presence = tokenCategoryPresence[token].Count;

                if (presence > MaxOtherCategoriesForToken + 1)
                {
                    continue;
                }

                var normalizedWeight = (double)frequency / categoryProductCount;

                if (normalizedWeight < MinNormalizedWeight)
                {
                    continue;
                }

                normalized[token] = normalizedWeight;
            }

            if (normalized.Count > 0)
            {
                filtered[category] = normalized;
            }
        }

        logger.LogInformation(
            "Category token index built: {Categories} categories, {TotalTokens} tokens.",
            filtered.Count,
            filtered.Values.Sum(w => w.Count));

        return CategoryTokenIndex.Create(filtered);
    }

    private static void AddTokens(HashSet<string> tokens, string? text)
    {
        if (string.IsNullOrWhiteSpace(text))
        {
            return;
        }

        foreach (var token in CategoryTokenIndex.Tokenize(text))
        {
            tokens.Add(token);
        }
    }
}

using Elastic.Clients.Elasticsearch;

namespace RP.RAG.Infrastructure.Elastic;

public sealed class ElasticsearchClientFactory
{
    private readonly ElasticsearchClient _client;

    public ElasticsearchClientFactory(
        IOptions<ElasticsearchOptions> options,
        ILogger<ElasticsearchClientFactory> logger)
    {
        var opts = options.Value;

        if (string.IsNullOrWhiteSpace(opts.Url))
            throw new InvalidOperationException(
                "Elasticsearch:Url is not configured.");

        if (!Uri.TryCreate(opts.Url, UriKind.Absolute, out var uri))
            throw new InvalidOperationException(
                $"Elasticsearch:Url is invalid: '{opts.Url}'.");

        if (opts.RequestTimeoutSeconds <= 0)
            throw new InvalidOperationException(
                "Elasticsearch:RequestTimeoutSeconds must be greater than zero.");

        if (string.IsNullOrWhiteSpace(opts.ProductIndexName))
            throw new InvalidOperationException(
                "Elasticsearch:ProductIndexName is not configured.");

        var settings = new ElasticsearchClientSettings(uri)
            .RequestTimeout(
                TimeSpan.FromSeconds(opts.RequestTimeoutSeconds))
            .DefaultIndex(opts.ProductIndexName);

        _client = new ElasticsearchClient(settings);

        logger.LogInformation(
            "Elasticsearch client created. Url={Url}, DefaultIndex={Index}, Timeout={Timeout}s",
            opts.Url,
            opts.ProductIndexName,
            opts.RequestTimeoutSeconds);
    }

    public ElasticsearchClient Create() => _client;
}

=== FILE: src/RP.Rag.Infrastructure/Elastic/ProductElasticIndexer.cs ===
using Elastic.Clients.Elasticsearch;
using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using Microsoft.Extensions.Options;
using RP.Rag.Domain.Entities.Products;
using RP.Rag.Infrastructure.Data;
using RP.Rag.Infrastructure.Elastic.Models;
using RP.RAG.Infrastructure.Elastic.Models;
using System.Diagnostics;
using System.Security.Cryptography;
using System.Text;

namespace RP.RAG.Infrastructure.Elastic;

public sealed class ProductElasticIndexer(
    RpRagDbContext db,
    ElasticsearchClientFactory factory,
    ProductIndex index,
    IOptions<ElasticsearchOptions> options,
    ILogger<ProductElasticIndexer> logger)
{
    private const int BatchSize = 250;
    private const int MaxRetries = 3;

    public async Task<IndexResult> RunAsync(bool forceReindex = false, CancellationToken ct = default)
    {
        var sw = Stopwatch.StartNew();

        var client = factory.Create();
        var indexName = options.Value.ProductIndexName;

        if (forceReindex)
        {
            logger.LogInformation("Force reindex requested, deleting index first.");

            await index.DeleteAsync(ct);

            var products = await db.Products.Include(p => p.Sync).ToListAsync(ct);

            foreach (var product in products)
            {
                product.SetToInitialState();
            }

            await db.SaveChangesAsync(ct);
        }

        await index.EnsureCreatedAsync(ct);

        var existingHashes = forceReindex
            ? new Dictionary<int, string>()
            : await LoadHashesAsync(client, indexName, ct);

        logger.LogInformation("Elasticsearch has {Count} existing product hashes.", existingHashes.Count);

        var totalRead = 0;
        var indexed = 0;
        var unchanged = 0;
        var failed = 0;

        while (!ct.IsCancellationRequested)
        {
            await Task.Delay(TimeSpan.FromSeconds(60), ct);

            var pending = await LoadPendingSyncStatesAsync(ct);

            if (pending.Count == 0)
                break;

            totalRead += pending.Count;

            logger.LogInformation("Processing {Count} products for Elasticsearch.", pending.Count);

            var syncMap = pending.ToDictionary(s => s.ProductId);
            var toIndex = new List<ProductSearchDocument>(pending.Count);
            var alreadySynchronized = new List<int>();

            foreach (var sync in pending)
            {
                var document = ProductSearchDocumentMapper.ToDocument(sync.Product);

                document.SearchTextHash = ComputeHash(document.SearchText);

                if (existingHashes.TryGetValue(sync.ProductId, out var oldHash) && oldHash == document.SearchTextHash)
                {
                    alreadySynchronized.Add(sync.ProductId);
                    continue;
                }

                toIndex.Add(document);
            }

            if (alreadySynchronized.Count > 0)
            {
                var now = DateTime.UtcNow;

                foreach (var productId in alreadySynchronized)
                {
                    var sync = syncMap[productId];

                    sync.ContentChanged = false;
                    sync.ContentSyncedAt = now;
                    sync.ContentSyncRetries = 0;
                    sync.ContentSyncError = null;
                    sync.UpdatedAt = now;

                }

                unchanged += alreadySynchronized.Count;

                await db.SaveChangesAsync(ct);

                logger.LogInformation("Marked {Count} products as already synchronized.", alreadySynchronized.Count);
            }

            if (toIndex.Count == 0)
                continue;

            foreach (var batch in Chunk(toIndex, BatchSize))
            {
                ct.ThrowIfCancellationRequested();

                var result = await BulkIndexAsync(client, indexName, batch, ct);

                var now = DateTime.UtcNow;
                var documentMap = batch.ToDictionary(d => d.ProductId);

                foreach (var productId in result.Successful)
                {
                    if (!syncMap.TryGetValue(productId, out var sync))
                    {
                        logger.LogWarning("ProductSync not found for successfully indexed ProductId={ProductId}.", productId);
                        continue;
                    }

                    sync.ContentChanged = false;
                    sync.ContentSyncedAt = now;

                    sync.EmbeddingChanged = true;

                    sync.ContentSyncRetries = 0;
                    sync.ContentSyncError = null;
                    sync.UpdatedAt = now;

                    if (documentMap.TryGetValue(productId, out var document))
                        existingHashes[productId] = document.SearchTextHash;
                }

                foreach (var failure in result.Failed)
                {
                    if (!syncMap.TryGetValue(failure.Key, out var sync))
                    {
                        logger.LogWarning("ProductSync not found for failed ProductId={ProductId}.", failure.Key);
                        continue;
                    }

                    sync.ContentChanged = true;
                    sync.ContentSyncRetries++;
                    sync.ContentSyncError = Truncate(failure.Value, 500);
                    sync.UpdatedAt = now;
                }

                indexed += result.Successful.Count;
                failed += result.Failed.Count;

                await db.SaveChangesAsync(ct);

                logger.LogInformation(
                    "Progress: indexed {Indexed}, unchanged {Unchanged}, failed {Failed}.",
                    indexed,
                    unchanged,
                    failed);

                if (result.Failed.Count > 0)
                    break;
            }
        }

        sw.Stop();

        var indexResult = new IndexResult
        {
            TotalRead = totalRead,
            Indexed = indexed,
            Unchanged = unchanged,
            Failed = failed,
            DurationSeconds = sw.Elapsed.TotalSeconds,
            IsFullReindex = forceReindex
        };

        logger.LogInformation("Indexing complete in {Seconds:F1}s. Read: {Read}, Indexed: {Indexed}, Unchanged: {Unchanged}, Failed: {Failed}",
            indexResult.DurationSeconds,
            indexResult.TotalRead,
            indexResult.Indexed,
            indexResult.Unchanged,
            indexResult.Failed);

        return indexResult;
    }


    private async Task<List<ProductSync>> LoadPendingSyncStatesAsync(CancellationToken ct)
    {
        return await db.ProductSyncs
            .Include(s => s.Product)
                .ThenInclude(p => p.Category)
            .Include(s => s.Product)
                .ThenInclude(p => p.ProductTags)
                    .ThenInclude(pt => pt.Tag)
            .Include(s => s.Product)
                .ThenInclude(p => p.Documents)
            .Where(s => s.Product.IsActive && (s.ContentChanged && s.ContentSyncRetries < MaxRetries))
            .OrderBy(s => s.ProductId)
            .Take(BatchSize)
            .ToListAsync(ct);
    }

    private async Task<Dictionary<int, string>> LoadHashesAsync(ElasticsearchClient client, string indexName, CancellationToken ct)
    {
        var hashes = new Dictionary<int, string>();
        const int pageSize = 5000;

        IReadOnlyCollection<FieldValue>? searchAfter = null;

        while (true)
        {
            ct.ThrowIfCancellationRequested();

            var response = await client.SearchAsync<ProductSearchDocument>(
                s =>
                {
                    s.Indices(indexName)
                        .Size(pageSize)
                        .Sort(sort => sort.Field(f => f.ProductId, so => so.Order(SortOrder.Asc)))
                        .Source(src => src.Filter(f => f.Includes(
                            Infer.Fields<ProductSearchDocument>(p => p.ProductId, p => p.SearchTextHash))));

                    if (searchAfter is not null)
                        s.SearchAfter(searchAfter.ToList());
                },
                ct);

            if (!response.IsValidResponse)
            {
                logger.LogError("Failed to load existing Elasticsearch hashes: {Debug}", response.DebugInformation);
                throw new InvalidOperationException("Failed to load existing Elasticsearch hashes.");
            }

            if (response.Documents.Count == 0)
                break;

            foreach (var document in response.Documents)
                hashes[document.ProductId] = document.SearchTextHash;

            var lastHit = response.Hits.LastOrDefault();

            if (lastHit?.Sort is null || lastHit.Sort.Count == 0)
                break;

            searchAfter = lastHit.Sort;

            if (response.Documents.Count < pageSize)
                break;
        }

        return hashes;
    }

    private async Task<BulkIndexResult> BulkIndexAsync(ElasticsearchClient client, string indexName, IReadOnlyList<ProductSearchDocument> documents, CancellationToken ct)
    {
        if (documents.Count == 0)
            return new BulkIndexResult(new HashSet<int>(), new Dictionary<int, string>());

        var response = await client.BulkAsync(
            b =>
            {
                b.Index(indexName);

                foreach (var document in documents)
                    b.Index(document, operation => operation.Id(document.ProductId.ToString()));
            },
            ct);

        if (!response.IsValidResponse)
        {
            logger.LogError("Elasticsearch bulk index failed: {Debug}", response.DebugInformation);

            return new BulkIndexResult(
                new HashSet<int>(),
                documents.ToDictionary(d => d.ProductId, _ => response.DebugInformation));
        }

        if (response.Items is null)
        {
            logger.LogError("Elasticsearch bulk response did not contain items.");

            return new BulkIndexResult(
                new HashSet<int>(),
                documents.ToDictionary(d => d.ProductId, _ => "Elasticsearch bulk response did not contain items."));
        }

        var successful = new HashSet<int>();
        var failed = new Dictionary<int, string>();

        foreach (var item in response.Items)
        {
            if (item.Error is not null)
            {
                logger.LogError(
                    "Elasticsearch item {Id} failed: {Type} - {Reason}",
                    item.Id,
                    item.Error.Type,
                    item.Error.Reason);

                if (int.TryParse(item.Id, out var productId))
                    failed[productId] = $"{item.Error.Type}: {item.Error.Reason}";

                continue;
            }

            if (int.TryParse(item.Id, out var successfulProductId))
                successful.Add(successfulProductId);
        }

        return new BulkIndexResult(successful, failed);
    }

    private static string ComputeHash(string text)
    {
        var bytes = SHA256.HashData(Encoding.UTF8.GetBytes(text));
        return Convert.ToHexString(bytes);
    }

    private static IEnumerable<List<T>> Chunk<T>(IReadOnlyList<T> source, int size)
    {
        for (var i = 0; i < source.Count; i += size)
        {
            var count = Math.Min(size, source.Count - i);
            var batch = new List<T>(count);

            for (var j = 0; j < count; j++)
                batch.Add(source[i + j]);

            yield return batch;
        }
    }

    private static string Truncate(string? value, int max)
    {
        if (string.IsNullOrEmpty(value))
            return string.Empty;

        return value.Length <= max
            ? value
            : value[..max] + "…";
    }

    private sealed record BulkIndexResult(HashSet<int> Successful, Dictionary<int, string> Failed);
}

    public string ModelName => _modelName;

    public OllamaEmbeddingGenerator(
        IHttpClientFactory httpFactory,
        IOptions<OllamaOptions> options,
        ILogger<OllamaEmbeddingGenerator> logger)
    {
        _http = httpFactory.CreateClient("Ollama");
        _logger = logger;
        _modelName = options.Value.EmbeddingModel;

        _logger.LogInformation(
            "OllamaEmbeddingGenerator configured. Model={Model}, Dims={Dims}",
            _modelName, ExpectedDimensions);
    }

    public async Task<Vector> GenerateAsync(string text, CancellationToken ct = default)
    {
        var results = await GenerateBatchAsync(new[] { text }, ct);
        return results[0];
    }

    public async Task<Vector[]> GenerateBatchAsync(
        IReadOnlyList<string> texts,
        CancellationToken ct = default)
    {
        if (texts.Count == 0)
            return Array.Empty<Vector>();

        var request = new OllamaEmbedRequest
        {
            Model = _modelName,
            Input = texts.ToList()
        };

        using var response = await _http.PostAsJsonAsync(
            "/api/embed", request, ct);

        if (!response.IsSuccessStatusCode)
        {
            var body = await response.Content.ReadAsStringAsync(ct);
            throw new InvalidOperationException(
                $"Ollama returned {response.StatusCode}: {body}");
        }

        var result = await response.Content
            .ReadFromJsonAsync<OllamaEmbedResponse>(ct);

        if (result?.Embeddings is null
            || result.Embeddings.Count != texts.Count)
        {
            throw new InvalidOperationException(
                $"Ollama returned {result?.Embeddings?.Count ?? 0} " +
                $"embeddings for {texts.Count} inputs.");
        }

        var vectors = new Vector[result.Embeddings.Count];

        for (var i = 0; i < result.Embeddings.Count; i++)
        {
            var v = result.Embeddings[i];

            if (v.Length != ExpectedDimensions)
                throw new InvalidOperationException(
                    $"Expected {ExpectedDimensions} dims, got {v.Length}.");

            vectors[i] = new Vector(v);
        }

        return vectors;
    }
}

using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using RP.Rag.Infrastructure.Data;
using RP.RAG.Application.Catalog;
using RP.RAG.Application.Search;
using RP.RAG.Application.Search.Models;
using System.Diagnostics;

namespace RP.RAG.Infrastructure.Search;

public sealed class HybridSearchService(
    ILexicalSearch lexical,
    ISemanticSearch semantic,
    IProductCatalogService catalog,
    IDbContextFactory<RpRagDbContext> dbFactory,
    CategoryTokenIndexCache categoryIndexCache,
    ILogger<HybridSearchService> logger) : IHybridSearch
{
    private const string StrategyName = "Hybrid";

    private const int MinCandidates = 20;
    private const int MaxCandidates = 100;
    private const int CandidateMultiplier = 4;
    private const int ChunkFetchMultiplier = 3;

    private const int MinTopProducts = 1;
    private const int MaxTopProducts = 20;
    private const int MinChunksPerProduct = 1;
    private const int MaxChunksPerProduct = 5;

    private const double LexicalRankFusionK = 60.0;
    private const double NameTokenOverlapBoost = 0.005;
    private const double CategoryMatchBoost = 0.020;
    private const double CategoryMismatchPenalty = 0.010;
    private const double TagMatchBoost = 0.010;

    private static readonly string[] LeadChunkTypes = ["summary", "description"];

    public async Task<HybridRetrieval> RetrieveAsync(
        string query,
        int topProducts = 5,
        int chunksPerProduct = 2,
        bool onlyActive = true,
        CancellationToken ct = default)
    {
        if (string.IsNullOrWhiteSpace(query))
        {
            return HybridRetrieval.Empty(query);
        }

        topProducts = Math.Clamp(topProducts, MinTopProducts, MaxTopProducts);
        chunksPerProduct = Math.Clamp(chunksPerProduct, MinChunksPerProduct, MaxChunksPerProduct);

        var candidateCount = ResolveCandidateCount(topProducts);

        var totalSw = Stopwatch.StartNew();

        var lexicalTask = RunLexicalAsync(query, candidateCount, onlyActive, ct);
        var semanticTask = RunSemanticAsync(query, candidateCount * ChunkFetchMultiplier, onlyActive, ct);

        await Task.WhenAll(lexicalTask, semanticTask);

        var lexicalResult = await lexicalTask;
        var semanticChunks = await semanticTask;

        var lexicalIds = lexicalResult.Hits.Select(h => h.ProductId).ToList();

        var semanticProductIds = semanticChunks
            .Select(c => c.ProductId)
            .ToHashSet();

        var lexicalOnlyIds = lexicalIds
            .Take(topProducts * 2)
            .Where(id => !semanticProductIds.Contains(id))
            .ToList();

        var lexicalOnlyChunks = lexicalOnlyIds.Count == 0
            ? new List<ChunkHit>()
            : await LoadLeadChunksAsync(lexicalOnlyIds, lexicalIds, onlyActive, ct);

        var fused = HybridRanker.Fuse(semanticChunks, lexicalIds, lexicalOnlyChunks);

        var withCategorySignal = await ApplyCategorySignalAsync(fused, query, ct);
        var withTagSignal = await ApplyTagSignalAsync(withCategorySignal, query, ct);
        var withNameBoost = await ApplyNameTokenBoostAsync(withTagSignal, query, ct);

        var ranked = withNameBoost;

        var groups = ranked
            .GroupBy(c => c.ProductId)
            .Take(topProducts)
            .ToList();

        var productIds = groups.Select(g => g.Key).ToList();

        var chunks = groups
            .SelectMany(g => g
                .OrderByDescending(c => c.Score)
                .Take(chunksPerProduct))
            .ToList();

        totalSw.Stop();

        logger.LogInformation(
            "Hybrid retrieval '{Query}': products={ProductCount}, chunks={ChunkCount}, total={TotalMs}ms",
            query,
            productIds.Count,
            chunks.Count,
            totalSw.ElapsedMilliseconds);

        return new HybridRetrieval(query, totalSw.ElapsedMilliseconds, productIds, chunks);
    }

    public async Task<SearchResult> SearchAsync(
        string query,
        int topK = 10,
        bool onlyActive = true,
        CancellationToken ct = default)
    {
        if (string.IsNullOrWhiteSpace(query))
        {
            return EmptyResult(query);
        }

        topK = Math.Clamp(topK, MinTopProducts, MaxTopProducts);

        var totalSw = Stopwatch.StartNew();

        var retrieval = await RetrieveAsync(query, topK, chunksPerProduct: 1, onlyActive, ct);

        if (retrieval.ProductIds.Count == 0)
        {
            totalSw.Stop();
            return EmptyResult(query, totalSw.ElapsedMilliseconds);
        }

        var cards = await catalog.GetCardsAsync(retrieval.ProductIds, onlyActive, ct);

        var chunksByProduct = retrieval.Chunks
            .GroupBy(c => c.ProductId)
            .ToDictionary(g => g.Key, g => g.First());

        var hits = new List<SearchHit>(retrieval.ProductIds.Count);

        foreach (var productId in retrieval.ProductIds)
        {
            if (!cards.TryGetValue(productId, out var card))
            {
                continue;
            }

            chunksByProduct.TryGetValue(productId, out var chunk);

            hits.Add(new SearchHit
            {
                ProductId = card.ProductId,
                Sku = card.Sku,
                Name = card.Name,
                Summary = card.Summary,
                CategoryName = card.CategoryName,
                Tags = card.Tags,
                Price = card.Price,
                StockCount = card.StockCount,
                IsActive = card.IsActive,
                Score = chunk?.Score ?? 0,
                Highlight = chunk?.Text
            });
        }

        totalSw.Stop();

        return new SearchResult
        {
            Query = query,
            Strategy = StrategyName,
            Total = hits.Count,
            TookMs = totalSw.ElapsedMilliseconds,
            Hits = hits
        };
    }

    private async Task<SearchResult> RunLexicalAsync(
        string query,
        int candidates,
        bool onlyActive,
        CancellationToken ct)
    {
        try
        {
            return await lexical.SearchAsync(query, candidates, onlyActive, ct);
        }
        catch (Exception ex)
        {
            logger.LogWarning(ex, "Lexical search failed for '{Query}'", query);
            return new SearchResult { Query = query, Strategy = "Lexical", Total = 0, TookMs = 0, Hits = [] };
        }
    }

    private async Task<IReadOnlyList<ChunkHit>> RunSemanticAsync(
        string query,
        int chunkLimit,
        bool onlyActive,
        CancellationToken ct)
    {
        try
        {
            return await semantic.SearchChunksAsync(query, chunkLimit, onlyActive, ct);
        }
        catch (Exception ex)
        {
            logger.LogWarning(ex, "Semantic search failed for '{Query}'", query);
            return [];
        }
    }

    private static int ResolveCandidateCount(int topProducts) =>
        Math.Clamp(topProducts * CandidateMultiplier, MinCandidates, MaxCandidates);

    private async Task<List<ChunkHit>> LoadLeadChunksAsync(
        List<int> lexicalOnlyProductIds,
        List<int> allLexicalProductIds,
        bool onlyActive,
        CancellationToken ct)
    {
        if (lexicalOnlyProductIds.Count == 0)
        {
            return [];
        }

        var lexicalRankById = allLexicalProductIds
            .Select((id, index) => (Id: id, Rank: index + 1))
            .ToDictionary(x => x.Id, x => x.Rank);

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var rows = await db.ProductChunks
            .AsNoTracking()
            .Where(c => lexicalOnlyProductIds.Contains(c.ProductId))
            .Where(c => !onlyActive || c.IsActive)
            .Where(c => c.Ordinal == 0 && LeadChunkTypes.Contains(c.ChunkType))
            .Select(c => new { c.Id, c.ProductId, c.ChunkType, c.Header, c.ChunkText })
            .ToListAsync(ct);

        var chunks = new List<ChunkHit>(rows.Count);

        foreach (var row in rows)
        {
            var rank = lexicalRankById.GetValueOrDefault(row.ProductId, allLexicalProductIds.Count + 1);
            var syntheticScore = 1.0 / (LexicalRankFusionK + rank);

            chunks.Add(new ChunkHit(row.Id, row.ProductId, row.ChunkType, row.Header, row.ChunkText, syntheticScore));
        }

        return chunks;
    }

    private async Task<List<ChunkHit>> ApplyCategorySignalAsync(
        List<ChunkHit> fused,
        string query,
        CancellationToken ct)
    {
        if (fused.Count == 0)
        {
            return fused;
        }

        var index = categoryIndexCache.Current;

        if (index.CategoryCount == 0)
        {
            return fused;
        }

        var detectedCategory = index.DetectCategory(query);

        if (detectedCategory is null)
        {
            return fused;
        }

        logger.LogInformation(
            "Category signal: inferred '{Category}' for query '{Query}'",
            detectedCategory,
            query);

        var productIds = fused
            .Select(c => c.ProductId)
            .Distinct()
            .ToList();

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var productCategories = await db.Products
            .AsNoTracking()
            .Where(p => productIds.Contains(p.Id))
            .Select(p => new
            {
                p.Id,
                CategoryName = p.Category != null ? p.Category.Name : string.Empty
            })
            .ToDictionaryAsync(p => p.Id, p => p.CategoryName, ct);

        var adjusted = new List<ChunkHit>(fused.Count);

        foreach (var chunk in fused)
        {
            var categoryName = productCategories.GetValueOrDefault(chunk.ProductId, string.Empty);

            var isMatch = string.Equals(categoryName, detectedCategory, StringComparison.OrdinalIgnoreCase);

            var adjustment = isMatch ? CategoryMatchBoost : -CategoryMismatchPenalty;

            adjusted.Add(chunk with { Score = chunk.Score + adjustment });
        }

        return adjusted
            .OrderByDescending(c => c.Score)
            .ToList();
    }

    private async Task<List<ChunkHit>> ApplyTagSignalAsync(
        List<ChunkHit> fused,
        string query,
        CancellationToken ct)
    {
        if (fused.Count == 0)
        {
            return fused;
        }

        var productIds = fused
            .Select(c => c.ProductId)
            .Distinct()
            .ToList();

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var knownTagNames = await db.Tags
            .AsNoTracking()
            .Select(t => t.Name)
            .ToListAsync(ct);

        if (knownTagNames.Count == 0)
        {
            return fused;
        }

        var knownTags = knownTagNames.ToHashSet(StringComparer.OrdinalIgnoreCase);

        var queryTokens = CategoryTokenIndex.Tokenize(query);

        var queryTags = queryTokens
            .Where(t => knownTags.Contains(t))
            .ToList();

        if (queryTags.Count == 0)
        {
            return fused;
        }

        logger.LogInformation(
            "Tag signal: matched query tags [{Tags}]",
            string.Join(", ", queryTags));

        var productTags = await db.ProductTags
            .AsNoTracking()
            .Where(pt => productIds.Contains(pt.ProductId))
            .Select(pt => new { pt.ProductId, TagName = pt.Tag.Name })
            .ToListAsync(ct);

        var tagsByProduct = productTags
            .GroupBy(pt => pt.ProductId)
            .ToDictionary(
                g => g.Key,
                g => g.Select(x => x.TagName).ToHashSet(StringComparer.OrdinalIgnoreCase));

        var adjusted = new List<ChunkHit>(fused.Count);

        foreach (var chunk in fused)
        {
            if (!tagsByProduct.TryGetValue(chunk.ProductId, out var tags))
            {
                adjusted.Add(chunk);
                continue;
            }

            var matchedTags = queryTags.Count(qt => tags.Contains(qt));
            var adjustment = matchedTags * TagMatchBoost;

            adjusted.Add(chunk with { Score = chunk.Score + adjustment });
        }

        return adjusted
            .OrderByDescending(c => c.Score)
            .ToList();
    }

    private async Task<List<ChunkHit>> ApplyNameTokenBoostAsync(
        List<ChunkHit> fused,
        string query,
        CancellationToken ct)
    {
        if (fused.Count == 0)
        {
            return fused;
        }

        var queryTokens = CategoryTokenIndex.Tokenize(query);

        if (queryTokens.Count == 0)
        {
            return fused;
        }

        var productIds = fused
            .Select(c => c.ProductId)
            .Distinct()
            .ToList();

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var productNames = await db.Products
            .AsNoTracking()
            .Where(p => productIds.Contains(p.Id))
            .Select(p => new { p.Id, p.Name })
            .ToDictionaryAsync(p => p.Id, p => p.Name, ct);

        var boosted = new List<ChunkHit>(fused.Count);

        foreach (var chunk in fused)
        {
            var name = productNames.GetValueOrDefault(chunk.ProductId, string.Empty);
            var nameTokens = CategoryTokenIndex.Tokenize(name);

            var overlap = 0;

            foreach (var token in nameTokens)
            {
                if (queryTokens.Contains(token))
                {
                    overlap++;
                }
            }

            var adjustment = overlap * NameTokenOverlapBoost;

            boosted.Add(chunk with { Score = chunk.Score + adjustment });
        }

        return boosted
            .OrderByDescending(c => c.Score)
            .ToList();
    }

    private static SearchResult EmptyResult(string query, long tookMs = 0) => new()
    {
        Query = query,
        Strategy = StrategyName,
        Total = 0,
        TookMs = tookMs,
        Hits = []
    };

public sealed class LexicalSearchService(
    ElasticsearchClientFactory factory,
    IDbContextFactory<RpRagDbContext> dbFactory,
    IOptions<ElasticsearchOptions> options,
    ILogger<LexicalSearchService> logger) : ILexicalSearch
{
    private const string StrategyName = "Lexical";

    private const int MaxCandidateMultiplier = 5;
    private const int MinCandidateCount = 50;
    private const int MaxCandidateCount = 200;

    private const int ExactNameBoost = 100;
    private const int ExactSkuBoost = 100;
    private const int ExactCategoryBoost = 50;
    private const int NamePhraseBoost = 25;
    private const int SummaryPhraseBoost = 40;
    private const int NamePartialBoost = 10;
    private const int SummaryPartialBoost = 15;
    private const int MultiMatchBoost = 1;
    private const int TagsBoost = 150;

    private const string PartialMatchRule = "2<75%";
    private const string SingleTermRule = "1";

    private static readonly string[] MultiMatchFields =
    [
        "name^8",
        "summary^3",
        "description^1",
        "searchText^0.5"
    ];

    public async Task<SearchResult> SearchAsync(
        string query,
        int topK = 10,
        bool onlyActive = true,
        CancellationToken cancellationToken = default)
    {
        if (string.IsNullOrWhiteSpace(query) || topK <= 0)
        {
            return EmptyResult(query);
        }

        query = query.Trim();

        var indexName = options.Value.ProductIndexName;
        var client = factory.Create();

        var candidateSize = ResolveCandidateSize(topK, onlyActive);

        var response = await client.SearchAsync<ProductSearchDocument>(
            s => s.Indices(indexName)
                .Size(candidateSize)
                .TrackTotalHits(true)
                .Query(q => BuildLexicalQuery(q, query))
                .Source(src => src.Filter(f => f.Includes(Infer.Fields<ProductSearchDocument>(p => p.ProductId)))),
            cancellationToken);

        if (!response.IsValidResponse)
        {
            logger.LogError(
                "Elasticsearch lexical search failed. Query={Query}, Index={Index}, Debug={Debug}",
                query,
                indexName,
                response.DebugInformation);

            throw new InvalidOperationException(
                $"Elasticsearch lexical search failed. {response.DebugInformation}");
        }

        var rankedHits = ExtractRankedHits(response);

        if (rankedHits.Count == 0)
        {
            return ResultWithoutHits(query, response);
        }

        var products = await LoadProductsAsync(rankedHits, onlyActive, cancellationToken);

        var hits = BuildHits(rankedHits, products, topK);

        logger.LogInformation(
            "Lexical search '{Query}': total={Total}, returned={Returned}, {Ms}ms",
            query,
            response.Total,
            hits.Count,
            response.Took);

        return new SearchResult
        {
            Query = query,
            Strategy = StrategyName,
            Total = response.Total,
            TookMs = response.Took,
            Hits = hits
        };
    }

    private static int ResolveCandidateSize(int topK, bool onlyActive)
    {
        if (!onlyActive)
        {
            return Math.Min(topK, MaxCandidateCount);
        }

        return Math.Min(
            Math.Max(topK * MaxCandidateMultiplier, MinCandidateCount),
            MaxCandidateCount);
    }

    private static List<(int ProductId, double? Score)> ExtractRankedHits(
        SearchResponse<ProductSearchDocument> response)
    {
        var rankedHits = new List<(int ProductId, double? Score)>();
        var seen = new HashSet<int>();

        foreach (var hit in response.Hits)
        {
            var productId = int.TryParse(hit.Id, out var idFromDocument)
                ? idFromDocument
                : hit.Source?.ProductId ?? 0;

            if (productId > 0 && seen.Add(productId))
            {
                rankedHits.Add((productId, hit.Score));
            }
        }

        return rankedHits;
    }

    private async Task<Dictionary<int, Product>> LoadProductsAsync(
        List<(int ProductId, double? Score)> rankedHits,
        bool onlyActive,
        CancellationToken cancellationToken)
    {
        var rankedIds = rankedHits.Select(x => x.ProductId).ToList();

        await using var db = await dbFactory.CreateDbContextAsync(cancellationToken);

        return await db.Products
            .AsNoTracking()
            .Include(p => p.Category)
            .Include(p => p.ProductTags)
                .ThenInclude(pt => pt.Tag)
            .Where(p => rankedIds.Contains(p.Id))
            .Where(p => !onlyActive || p.IsActive)
            .ToDictionaryAsync(p => p.Id, cancellationToken);
    }

    private static List<SearchHit> BuildHits(
        List<(int ProductId, double? Score)> rankedHits,
        Dictionary<int, Product> products,
        int topK)
    {
        var hits = new List<SearchHit>(Math.Min(topK, products.Count));

        foreach (var (productId, score) in rankedHits)
        {
            if (!products.TryGetValue(productId, out var product))
            {
                continue;
            }

            hits.Add(new SearchHit
            {
                ProductId = product.Id,
                Sku = product.SKU,
                Name = product.Name,
                Summary = product.Summary,
                Description = product.Description,
                CategoryName = product.Category?.Name ?? string.Empty,
                Tags = product.ProductTags.Select(pt => pt.Tag.Name).ToList(),
                Price = product.Price,
                StockCount = product.StockCount,
                IsActive = product.IsActive,
                Score = score ?? 0
            });

            if (hits.Count >= topK)
            {
                break;
            }
        }

        return hits;
    }

    private static SearchResult EmptyResult(string query) => new()
    {
        Query = query,
        Strategy = StrategyName,
        Total = 0,
        TookMs = 0,
        Hits = []
    };

    private static SearchResult ResultWithoutHits(
        string query,
        SearchResponse<ProductSearchDocument> response) => new()
        {
            Query = query,
            Strategy = StrategyName,
            Total = response.Total,
            TookMs = response.Took,
            Hits = []
        };

    private static Query BuildLexicalQuery(
        QueryDescriptor<ProductSearchDocument> q,
        string query)
    {
        var queryTerms = query
            .Trim()
            .ToLowerInvariant()
            .Split(' ', StringSplitOptions.RemoveEmptyEntries | StringSplitOptions.TrimEntries);

        var tagTerms = queryTerms
            .Select(t => FieldValue.String(t))
            .ToArray();

        var outerMinimumShouldMatch = queryTerms.Length > 1 ? 2 : 1;

        return q.Bool(b =>
        {
            b.Must(q => q.Bool(mb => mb
                .Should(
                    q => q.Match(m => m.Field("name").Query(query).MinimumShouldMatch(SingleTermRule)),
                    q => q.Match(m => m.Field("categoryName").Query(query).MinimumShouldMatch(SingleTermRule)),
                    q => q.Match(m => m.Field("summary").Query(query).MinimumShouldMatch(PartialMatchRule)))
                .MinimumShouldMatch(1)));

            b.Should(
                q => q.Term(t => t.Field("name.keyword").Value(query).CaseInsensitive(true).Boost(ExactNameBoost)),
                q => q.Term(t => t.Field("sku").Value(query).CaseInsensitive(true).Boost(ExactSkuBoost)),
                q => q.Term(t => t.Field("categoryName.keyword").Value(query).CaseInsensitive(true).Boost(ExactCategoryBoost)),
                q => q.MatchPhrase(mp => mp.Field("name").Query(query).Boost(NamePhraseBoost)),
                q => q.MatchPhrase(mp => mp.Field("summary").Query(query).Boost(SummaryPhraseBoost)),
                q => q.Match(m => m.Field("name").Query(query).MinimumShouldMatch(PartialMatchRule).Boost(NamePartialBoost)),
                q => q.Match(m => m.Field("summary").Query(query).MinimumShouldMatch(PartialMatchRule).Boost(SummaryPartialBoost)),
                q => q.MultiMatch(mm => mm
                    .Query(query)
                    .Fields(MultiMatchFields)
                    .Type(TextQueryType.BestFields)
                    .MinimumShouldMatch(PartialMatchRule)
                    .Boost(MultiMatchBoost)),
                q => q.Terms(t => t.Field("tags").Terms(new TermsQueryField(tagTerms)).Boost(TagsBoost)));

            b.MinimumShouldMatch(outerMinimumShouldMatch);
        });
    }
}

using Microsoft.EntityFrameworkCore;
using Microsoft.Extensions.Logging;
using Pgvector.EntityFrameworkCore;
using RP.Rag.Domain.Entities.Products;
using RP.Rag.Infrastructure.Data;
using RP.RAG.Application.Embeddings;
using RP.RAG.Application.Search;
using RP.RAG.Application.Search.Models;
using System.Diagnostics;

namespace RP.RAG.Infrastructure.Search;

public sealed class SemanticSearchService(
    IDbContextFactory<RpRagDbContext> dbFactory,
    IEmbeddingGenerator embedder,
    ILogger<SemanticSearchService> logger) : ISemanticSearch
{
    private const string StrategyName = "Semantic";

    private const int MaxChunkLimit = 500;
    private const int MinChunkLimit = 1;
    private const int MaxTopK = 50;
    private const int MinTopK = 1;
    private const int ChunkOverFetchMultiplier = 3;

    public async Task<IReadOnlyList<ChunkHit>> SearchChunksAsync(
        string query,
        int limit = 30,
        bool onlyActive = true,
        CancellationToken ct = default)
    {
        if (string.IsNullOrWhiteSpace(query))
        {
            return [];
        }

        limit = Math.Clamp(limit, MinChunkLimit, MaxChunkLimit);

        var queryVector = await embedder.GenerateAsync(query, ct);
        var modelName = embedder.ModelName;

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        var rows = await db.ProductChunks
            .AsNoTracking()
            .Where(c => !onlyActive || c.IsActive)
            .Where(c => c.Embedding != null && c.EmbeddingModel == modelName)
            .Select(c => new
            {
                c.Id,
                c.ProductId,
                c.ChunkType,
                c.Header,
                c.ChunkText,
                Distance = c.Embedding!.CosineDistance(queryVector)
            })
            .OrderBy(x => x.Distance)
            .Take(limit)
            .ToListAsync(ct);

        var hits = new List<ChunkHit>(rows.Count);

        foreach (var row in rows)
        {
            hits.Add(new ChunkHit(
                row.Id,
                row.ProductId,
                row.ChunkType,
                row.Header,
                row.ChunkText,
                DistanceToScore(row.Distance)));
        }

        return hits;
    }

    public async Task<SearchResult> SearchAsync(
        string query,
        int topK = 10,
        bool onlyActive = true,
        CancellationToken ct = default)
    {
        if (string.IsNullOrWhiteSpace(query))
        {
            return EmptyResult(query);
        }

        topK = Math.Clamp(topK, MinTopK, MaxTopK);

        var totalSw = Stopwatch.StartNew();
        var embedSw = Stopwatch.StartNew();

        var chunkFetchLimit = topK * ChunkOverFetchMultiplier;

        var chunks = await SearchChunksAsync(query, chunkFetchLimit, onlyActive, ct);

        embedSw.Stop();

        if (chunks.Count == 0)
        {
            totalSw.Stop();
            logger.LogInformation(
                "Semantic search '{Query}': no chunks matched in {Ms}ms",
                query,
                totalSw.ElapsedMilliseconds);

            return ResultWithoutHits(query, totalSw.ElapsedMilliseconds);
        }

        var bestChunks = SelectBestChunkPerProduct(chunks, topK);

        var dbSw = Stopwatch.StartNew();
        var products = await LoadProductsAsync(bestChunks, onlyActive, ct);
        dbSw.Stop();

        var hits = BuildHits(bestChunks, products);

        totalSw.Stop();

        logger.LogInformation(
            "Semantic search '{Query}': {Chunks} chunks, {Hits} hits, embed+search={EmbedMs}ms, db={DbMs}ms, total={TotalMs}ms",
            query,
            chunks.Count,
            hits.Count,
            embedSw.ElapsedMilliseconds,
            dbSw.ElapsedMilliseconds,
            totalSw.ElapsedMilliseconds);

        return new SearchResult
        {
            Query = query,
            Strategy = StrategyName,
            Total = hits.Count,
            TookMs = totalSw.ElapsedMilliseconds,
            Hits = hits
        };
    }

    private static List<ChunkHit> SelectBestChunkPerProduct(
        IReadOnlyList<ChunkHit> chunks,
        int topK)
    {
        var bestByProduct = new Dictionary<int, ChunkHit>(chunks.Count);
        var insertionOrder = new List<int>(chunks.Count);

        foreach (var chunk in chunks)
        {
            if (!bestByProduct.TryGetValue(chunk.ProductId, out var existing))
            {
                bestByProduct[chunk.ProductId] = chunk;
                insertionOrder.Add(chunk.ProductId);
                continue;
            }

            if (chunk.Score > existing.Score)
            {
                bestByProduct[chunk.ProductId] = chunk;
            }
        }

        var result = new List<ChunkHit>(Math.Min(topK, bestByProduct.Count));

        foreach (var productId in insertionOrder)
        {
            if (result.Count >= topK)
            {
                break;
            }

            result.Add(bestByProduct[productId]);
        }

        return result;
    }

    private async Task<Dictionary<int, Product>> LoadProductsAsync(
        IReadOnlyList<ChunkHit> chunks,
        bool onlyActive,
        CancellationToken ct)
    {
        var productIds = chunks
            .Select(c => c.ProductId)
            .Distinct()
            .ToList();

        await using var db = await dbFactory.CreateDbContextAsync(ct);

        return await db.Products
            .AsNoTracking()
            .Include(p => p.Category)
            .Include(p => p.ProductTags)
                .ThenInclude(pt => pt.Tag)
            .Where(p => productIds.Contains(p.Id))
            .Where(p => !onlyActive || p.IsActive)
            .ToDictionaryAsync(p => p.Id, ct);
    }

    private static List<SearchHit> BuildHits(
        IReadOnlyList<ChunkHit> chunks,
        Dictionary<int, Product> products)
    {
        var hits = new List<SearchHit>(chunks.Count);

        foreach (var chunk in chunks)
        {
            if (!products.TryGetValue(chunk.ProductId, out var product))
            {
                continue;
            }

            hits.Add(new SearchHit
            {
                ProductId = product.Id,
                Sku = product.SKU,
                Name = product.Name,
                Summary = product.Summary,
                Description = product.Description,
                CategoryName = product.Category?.Name ?? string.Empty,
                Tags = product.ProductTags.Select(pt => pt.Tag.Name).ToList(),
                Price = product.Price,
                StockCount = product.StockCount,
                IsActive = product.IsActive,
                Score = chunk.Score,
                Highlight = chunk.Text
            });
        }

        return hits;
    }

    private static double DistanceToScore(double distance)
    {
        if (double.IsNaN(distance) || double.IsInfinity(distance))
        {
            return 0;
        }

        return Math.Exp(-distance);
    }

    private static SearchResult EmptyResult(string query) => new()
    {
        Query = query,
        Strategy = StrategyName,
        Total = 0,
        TookMs = 0,
        Hits = []
    };

    private static SearchResult ResultWithoutHits(string query, long tookMs) => new()
    {
        Query = query,
        Strategy = StrategyName,
        Total = 0,
        TookMs = tookMs,
        Hits = []
    };
}

        var suffix = string.IsNullOrWhiteSpace(locale) ? "" : $"_{locale}";

        var categories = await ReadAsync<List<CategorySeed>>(
            Path.Combine(seedDir, $"categories{suffix}.json"), ct);

        var tags = await ReadAsync<List<TagSeed>>(
            Path.Combine(seedDir, $"tags{suffix}.json"), ct);

        var products = await ReadAsync<List<ProductSeed>>(
            Path.Combine(seedDir, $"products{suffix}.json"), ct);

        logger.LogInformation(
            "Seed files loaded (locale={Locale}). Categories={C}, Tags={T}, Products={P}",
            string.IsNullOrEmpty(locale) ? "(default)" : locale,
            categories.Count, tags.Count, products.Count);

        var insertedCategories = 0;
        var insertedTags = 0;
        var insertedProducts = 0;
        var insertedDocuments = 0;

        await using var tx = await db.Database.BeginTransactionAsync(ct);

        try
        {
            insertedCategories = await InsertCategoriesAsync(categories, ct);
            insertedTags = await InsertTagsAsync(tags, ct);

            var (p, d) = await InsertProductsAsync(products, ct);
            insertedProducts = p;
            insertedDocuments = d;

            await SyncSequencesAsync(ct);

            await tx.CommitAsync(ct);
        }
        catch
        {
            await tx.RollbackAsync(ct);
            throw;
        }

        var result = new SeedResult
        {
            Categories = insertedCategories,
            Tags = insertedTags,
            Products = insertedProducts,
            Documents = insertedDocuments
        };

        logger.LogInformation(
            "Seed complete (insert-only). Inserted {Categories} categories, " +
            "{Tags} tags, {Products} products, {Documents} documents.",
            result.Categories, result.Tags, result.Products, result.Documents);

        return result;
    }

    private async Task ClearAsync(CancellationToken ct)
    {
        logger.LogWarning("Clearing existing seed data...");

        await db.Database.ExecuteSqlRawAsync(
            """
            TRUNCATE TABLE
                "ProductChunks",
                "ProductDocuments",
                "ProductTags",
                "ProductSyncs",
                "Products",
                "Tags",
                "ProductCategories"
            RESTART IDENTITY CASCADE;
            """,
            ct);
    }

    private async Task SyncSequencesAsync(CancellationToken ct)
    {
        const string sql =
            """
            SELECT setval(pg_get_serial_sequence('"ProductCategories"','Id'),
                          COALESCE((SELECT MAX("Id") FROM "ProductCategories"), 0) + 1,
                          false);
            SELECT setval(pg_get_serial_sequence('"Tags"','Id'),
                          COALESCE((SELECT MAX("Id") FROM "Tags"), 0) + 1,
                          false);
            SELECT setval(pg_get_serial_sequence('"Products"','Id'),
                          COALESCE((SELECT MAX("Id") FROM "Products"), 0) + 1,
                          false);
            SELECT setval(pg_get_serial_sequence('"ProductDocuments"','Id'),
                          COALESCE((SELECT MAX("Id") FROM "ProductDocuments"), 0) + 1,
                          false);
            SELECT setval(pg_get_serial_sequence('"ProductChunks"','Id'),
                          COALESCE((SELECT MAX("Id") FROM "ProductChunks"), 0) + 1,
                          false);
            """;

        await db.Database.ExecuteSqlRawAsync(sql, ct);
    }

    private static async Task<T> ReadAsync<T>(string path, CancellationToken ct)
    {
        if (!File.Exists(path))
            throw new FileNotFoundException($"Seed file not found: {path}");

        await using var stream = File.OpenRead(path);

        var result = await JsonSerializer.DeserializeAsync<T>(stream, JsonOptions, ct);

        return result ?? throw new InvalidOperationException($"Failed to deserialize {path}");
    }

    private async Task<int> InsertCategoriesAsync(List<CategorySeed> seeds, CancellationToken ct)
    {
        var existingIds = await db.Categories
            .Select(c => c.Id)
            .ToHashSetAsync(ct);

        var toInsert = seeds
            .Where(s => !existingIds.Contains(s.Id))
            .Select(s => new ProductCategory
            {
                Id = s.Id,
                Name = s.Name,
                Description = s.Description
            })
            .ToList();

        if (toInsert.Count == 0)
            return 0;

        db.Categories.AddRange(toInsert);
        await db.SaveChangesAsync(ct);

        return toInsert.Count;
    }

    private async Task<int> InsertTagsAsync(List<TagSeed> seeds, CancellationToken ct)
    {
        var existingIds = await db.Tags
            .Select(t => t.Id)
            .ToHashSetAsync(ct);

        var toInsert = seeds
            .Where(s => !existingIds.Contains(s.Id))
            .Select(s => new Tag { Id = s.Id, Name = s.Name })
            .ToList();

        if (toInsert.Count == 0)
            return 0;

        db.Tags.AddRange(toInsert);
        await db.SaveChangesAsync(ct);

        return toInsert.Count;
    }

    private async Task<(int products, int documents)> InsertProductsAsync(
        List<ProductSeed> seeds,
        CancellationToken ct)
    {
        var existingProductIds = await db.Products
            .Select(p => p.Id)
            .ToHashSetAsync(ct);

        var existingTagIds = await db.Tags
            .Select(t => t.Id)
            .ToHashSetAsync(ct);

        var newProducts = new List<Product>();

        foreach (var s in seeds)
        {
            if (existingProductIds.Contains(s.Id))
                continue;

            var p = new Product
            {
                Id = s.Id,
                Name = s.Name,
                Summary = s.Summary,
                SKU = s.Sku,
                Description = s.Description,
                IsActive = true,
                Price = s.Price,
                StockCount = s.StockCount,
                ProductCategoryId = s.ProductCategoryId,
                CreatedAt = DateTime.UtcNow,
                UpdatedAt = DateTime.UtcNow
            };

            foreach (var tagId in s.TagIds.Where(existingTagIds.Contains).Distinct())
                p.ProductTags.Add(new ProductTag { TagId = tagId });

            foreach (var d in s.Documents)
            {
                p.Documents.Add(new ProductDocument
                {
                    Type = d.Type,
                    Title = d.Title,
                    Content = d.Content,
                    IsActive = true,
                    CreatedAt = DateTime.UtcNow
                });
            }

            newProducts.Add(p);
        }

        if (newProducts.Count == 0)
            return (0, 0);

        db.Products.AddRange(newProducts);
        await db.SaveChangesAsync(ct);

        var docCount = newProducts.Sum(p => p.Documents.Count);
        return (newProducts.Count, docCount);
    }
}
